## 已完成的产品流程图

```
访客   浏览首页/类型页 → 分类筛选/标题搜索/标签检索 → 文章详情 → 作者主页
用户   注册 → 自动登录 → 写文章（草稿/发布）→ 我的文章（筛选/编辑/删除）
用户   个人中心 → 改头像与简介 → 作者主页同步更新
用户   刷新页面 → 用本地快照立即恢复登录态 → 后台用 /users/me 核对
```

## 设计方向

- 版式：编辑部（奶油纸底、衬线标题、零圆角、发丝线分区、编辑红强调）
- 两个签名功能：**继续阅读**（本地记录阅读进度，首页顶部续读条）、**两种版面**（技术文章宽版心、日常思考窄版心）
- 文章目录：作者在写作台勾选后，详情页在正文前渲染 `##` / `###` 生成的目录，点击平滑滚动到对应小节
- 标签导航：列表与详情里的标签可点击，跳到 `/?tag=标签名`。结果按**标签相关度**排序——完全相同 1.0，包含关系 0.5~0.9，拼写接近 ≤0.8，同分按发布时间倒序
- 封面：作者可选填 `cover_url`（显示在标题下方）；不填则完全不显示，也可直接用 Markdown 图片把封面放进正文
- 设计 token 全部集中在 `client/src/index.css` 的 CSS 变量里

### 部署时踩到的四个坑（都已修）

| 现象 | 根因 | 解决 |
|---|---|---|
| 函数不上线，`/api/*` 全 404 | 函数入口必须在 `cloud-functions/api/[[default]].js`，根级 `[[default]].js` 不在官方路由表里 | 文件挪到 `api/` 子目录 |
| 目录对了仍不识别 | 平台靠**静态分析**找入口，`export { default } from '...'` 这种转导出不算 | 改成 `import app ...; export default app;` |
| 函数跑起来但接口 404 | 平台会**剥掉 `/api` 前缀**，Express 收到的是 `/v1/articles` | `server/src/edge.ts` 里补回前缀，并设置 `trust proxy` |
| 刷新 `/login` 或直接访问子路由 404 | 静态托管没有 SPA 回退 | 根目录 `edgeone.json` 声明 `rewrites: /* → /index.html`（平台识别为 SPA fallback） |
